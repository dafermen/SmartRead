# Chrome Web Store submission

## Required material

- Product name, short description, and detailed description in English.
- Icons in all store-required sizes.
- Real screenshots of the popup and reading flow.
- Category, support contact, and supported language information.
- Privacy policy hosted at a public URL.
- Clear justification for every permission.

## Product declarations

The listing must match the shipped version:

- Single purpose: read web text aloud.
- Page text is processed locally.
- No telemetry or page-text transfer in the current version.
- Preferences are stored locally.
- The interface and documentation are English.
- Speech languages may vary according to installed voices.

## Pre-submission review

- Complete `docs/RELEASE_CHECKLIST.md`.
- Confirm that no remote code is present.
- Confirm that the ZIP contains only allowlisted release files.
- Review version and minimum Chrome compatibility.
- Test a clean installation of the final ZIP.
- Preserve evidence and a copy of the approved package.

Never publish a privacy declaration that was not verified against the exact submitted
code version.
